Kodescape Chat Widget — Dev Harness

Loads two independent widget instances against a local cms-api (http://localhost:5001) — one per siteId — to simulate Org A and Org B running side by side, per the Phase 1 Definition-of-Done checklist.

Set window.__KW_SITE_ID_A__ / window.__KW_SITE_ID_B__ in devtools before reload, or edit the values directly in index.html — these must match real ChatWidgetSettings.siteId values seeded in the local database with allowedDomains including localhost.
